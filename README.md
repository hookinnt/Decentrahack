# AI Agent for Predictive Risk & Treasury Management

🚀 **Автономный AI-агент, который спасает ваши криптоактивы от взломов на основе новостей.**

## 📌 Описание проекта
Блокчейн прозрачен, но смарт-контракты не умеют читать новости. Если в протоколе находят уязвимость, деньги утекают до того, как команда успевает нажать кнопку "Пауза".
Наше решение — **Мост между реальным миром и Web3 на базе Gemini 1.5 Pro**.

Агент непрерывно анализирует новостной фон среды. Если он видит критическое событие (например, хакерскую атаку или критический баг в протоколе), AI автономно оценивает риски и принимает решение: проигнорировать, подать сигнал тревоги или **отправить транзакцию в смарт-контракт**, чтобы заморозить средства (или перевести их в стейблкоины).

## 🛠 Технический стек
* **Логика AI**: Python 3, `google-generativeai` (Gemini 1.5 Pro), Pydantic
* **Смарт-контракт**: Solidity / Rust (в стадии разработки — Этап 2)
* **Аналитика и UI**: Colorama для красивого консольного дашборда-презентации

## 🚀 Как запустить Демо (Этап 1)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/hookinnt/Decentrahack.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd Decentrahack
   ```
3. Установите зависимости (рекомендуется использовать виртуальное окружение):
   ```bash
   pip install -r requirements.txt
   ```
4. Создайте файл `.env` в корневой папке проекта и вставьте ваш API ключ Gemini:
   ```env
   GEMINI_API_KEY=ваш_ключ
   ```

### Опция А: Запуск Web-интерфейса (Рекомендуется)
Полностью интерактивный дашборд.
```bash
python app.py
```
Откройте в браузере: `http://127.0.0.1:5000`

### Опция Б: Запуск консольного демо
Автоматизированный скрипт с примером обработки новостей в реальном времени.
```bash
python demo.py
```

## 🧠 Под Капотом: Как это работает
1. `news_feed.py` имитирует входящий поток новостей и твитов из интернета.
2. `analyzer.py` мгновенно пересылает текст новости в модель Gemini. Благодаря жесткому системному промпту (System Prompt), нейросеть возвращает ответ строго в формате JSON, оценивая уровень риска (`risk_score`) и сообщая, требуются ли блокчейн-действия (`action_required`).
3. `demo.py` визуализирует этот процесс в риал-тайм терминале — мы наглядно видим, как агент "понимает" новость и принимает решение на основе здравого смысла.
